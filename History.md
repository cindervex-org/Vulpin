In 2026, A Iranian programmer called "Armin Ghassemi" known as "Bat-script" and he created Vulpin.
The idea was Creating *Smallest possible programs* while having *many options* in a programming language.
The idea happened about internet speed, he thought of many people couldn't download huge program size, and he was afraid of games and apps size.

---

He started Creating Vulpin at age 15 at their parent's house with a cup of coffee + heart.
first release of Vulpin[0.1] made with python and released in "Bale messenger" in bale.ai then moved to GitHub with MIT license. 

He moved Vulpin from Python to rust because python wasn't fast at all...
He made Discord Server called "Vulpin community" that developer's can meet each other.
Then he moved Vulpin from Rust to C to make it Super faster
and Then He moved Vulpin from *C* to *Nasm* to have more control and release *Vasm (Vulpin asm)* by with.

* Humbrag project -> Humbrag is a project that is comming soon as feature of "vulpin" that connect's vulpin to Front-end.
*Humbrag* is simple, fast, and easy to use plugin! so wait for it.
